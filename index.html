Bekezdés & Karakter

Bekezdés: igazítás (bal, közép, jobb, sorkizárt), sorköz, térköz a bekezdések előtt/után, behúzások.

Címzés & Képletek

Minden képlet = jellel kezdődik.
Relatív címzés: A1, B5 (másoláskor változik).
Abszolút címzés: $A$1 (másoláskor rögzített).

Főbb Függvények

SZUM(), ÁTLAG(), DARAB(), MAX(), MIN().
Feltételes függvények: HA(feltétel; érték_ha_igaz; érték_ha_hamis).

Microsoft Access & Relációs Adatbázisok

Tanuld meg a struktúrált adattárolást, az elemi adattípusokat, az elsődleges kulcsok jelentőségét és a SQL lekérdezések használatát!

Táblák & Mezők

Az adatbázis alapja a tábla. A sorszintű entitások a rekordok, az oszlopok a mezők (adattípusokkal: Rövid szöveg, Szám, Dátum, AutoSzám).

Kulcsok & Kapcsolatok

Elsődleges kulcs (Primary Key): Egyedi azonosító a táblában.
Idegen kulcs (Foreign Key): Másik táblára mutató hivatkozás (1:N kapcsolat).

Lekérdezések (SQL)

Adatok kigyűjtése és szűrése feltételek alapján.
Alapvető szintaxis: SELECT mezők FROM tábla WHERE feltétel ORDER BY rendezés.

Programozás

Python Algoritmusok & Kódolás

A modern programozás legnépszerűbb nyelve. Sajátítsd el a változók, feltételek, ciklusok és listák használatát!

Változók & Típusok

Adatok tárolása névvel ellátott rekeszekben.
Típusok: int (egész), float (valós), str (szöveg), bool (logikai).

Feltételek (Elágazások)

A program döntéshozatala if, elif és else kulcsszavak segítségével. A blokkokat behúzás (4 szóköz) jelzi!

Ciklusok & Listák

Ismétlődő utasítások: for (számlálós) és while (feltételes) ciklus. Listák: [1, 2, 3] elemsorozatok tárolására.

példa_program.py 
# Számok átlagának kiszámítása Pythonban
szamok = [12, 45, 67, 89, 23]

def szamol_atlag(lista):
    osszeg = sum(lista)
    db = len(lista)
    return osszeg / db

atlag = szamol_atlag(szamok)
print(f"A számok átlaga: {atlag:.2f}")

if atlag >= 50:
    print("Sikeres teljesítmény!")
else:
    print("Szükséges még gyakorlás.")
Tipp: A Pythonban a behúzás (indentation) határozza meg a kódtömböket a kapcsos zárójelek helyett.
